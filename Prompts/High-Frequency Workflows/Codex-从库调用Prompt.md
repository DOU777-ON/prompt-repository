# Codex-从库调用Prompt

## 使用经验

- 适合在 Codex 开始复杂任务前先调用。
- 如果知道具体文件，直接指定文件路径更高效。
- 如果不知道具体文件，用任务描述让 Codex 自动检索。
- 调用前应优先参考当前 README 和高频工作流，避免按旧规则执行。
- 如果发现 Obsidian 库规则与 Codex 记忆中的规则不一致，应以本地库文件为准。
