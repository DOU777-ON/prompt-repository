# Workflow-High-Frequency-Task-Handling

## 使用经验

- 适合作为常规 Codex 任务的启动 Prompt。
- 与“请调用相关角色卡”组合使用时，适合专业任务。
- 与“请将这个提示词加入 Prompt 库”组合使用时，适合资产沉淀。
- 每次修改 Obsidian 库结构、模板或规则时，应同步更新 Codex 高频工作流、入库规则和调用规则。
- 执行任务时以当前本地 Prompt Repository 文件为准，不依赖旧记忆。
